## Provenance and caveats

This file was generated in a **non-interactive session**, so the skill's usual
per-acronym developer interview did not run. Every definition above is instead
grounded in this repo's own source — the `Used in` column cites where each term is
actually used, and the entries carrying a `file:line` reference are ones the repo
spells out in full somewhere.

Two entries are worth a human glance:

- **OATS** — the repo uses the name (`internal/testgenerated/oats/`, `oats-*` Make
  targets) but never expands it. "OpenTelemetry Acceptance Tests" comes from the
  upstream `grafana/oats` project, not from this codebase.
- **AZ** — appears only as the `inter-az.md` filename; the prose consistently writes
  "availability zones" in full.
