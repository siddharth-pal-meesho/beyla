# Acronyms

> Domain-specific acronyms used in this repo's code and docs. Generic programming
> acronyms (HTTP, JSON, gRPC, URL, API, JWT) are NOT listed here — only domain terms
> that a new engineer wouldn't infer from context.
>
> Auto-generated by /m-docs:acronyms-docs. Add entries as new acronyms are introduced.

| Acronym | Definition | Used in |
|---------|------------|---------|
| BPF | Berkeley Packet Filter — the in-kernel VM the probes run on; also the `CAP_BPF` Linux capability Beyla needs to load them | sources, wiki, pkg |
| BTF | BPF Type Format — kernel type metadata (`CONFIG_DEBUG_INFO_BTF`) that lets probes be portable across kernel versions | sources |
| CIDR | Classless Inter-Domain Routing — notation for the IP ranges in `BEYLA_NETWORK_CIDRS`, used to decorate network flows | sources, wiki |
| CNI | Container Network Interface — the Kubernetes plugin that assigns the pod IP; Beyla must attach after it runs | sources, pkg |
| DAC | Discretionary Access Control — as in `CAP_DAC_READ_SEARCH`, the capability that lets Beyla open other processes' ELF files | sources, charts |
| eBPF | extended Berkeley Packet Filter — the kernel technology Beyla uses to instrument processes without code changes | architecture, sources, wiki |
| ELF | Executable and Linkable Format — the Linux binary format Beyla parses to find instrumentation points | sources |
| JIT | Just-In-Time compilation — why JVM/.NET runtimes need different probe handling than statically compiled binaries | sources |
| LRU | Least Recently Used — the eviction policy on Beyla's bounded in-memory caches (attributes, eligible deployments) | pkg, wiki |
| OBI | OpenTelemetry eBPF Instrumentation — the upstream engine Beyla v3 is a distribution of; lives in `vendor/go.opentelemetry.io/obi` | architecture, wiki, pkg, devdocs |
| OCI | Open Container Initiative — the container image/runtime standard; `OCI container name` is a service-selection criterion | sources, pkg |
| OTel | OpenTelemetry — the observability standard Beyla exports to | architecture, sources, wiki |
| OTLP | OpenTelemetry Protocol — the wire protocol for exporting traces and metrics to a collector or backend | architecture, sources, wiki, pkg |
| PERFMON | Performance Monitoring — the `CAP_PERFMON` Linux capability required to attach perf-based probes | sources, charts |
| RBAC | Role-Based Access Control — the Kubernetes permissions the Helm chart grants for pod/ReplicaSet metadata | charts, sources, wiki |
| RED | Rate, Errors, Duration — the metrics methodology behind Beyla's application metrics and the shipped dashboard | architecture, sources |
| RSS | Resident Set Size — process physical memory, exported as `process.memory.usage` (from `vmRSS`); *not* the syndication format | pkg |
| TC | Traffic Control — the Linux kernel networking layer Beyla attaches network-flow probes to | sources |
| TCX | Traffic Control eXpress — the newer TC attach API; preferred over Netlink because it coexists with other agents such as Cilium | sources |
| UDS | Unix Domain Socket — one of the two transports for the health-check listener (UDS or TCP, never both) | architecture |
