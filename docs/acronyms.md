# Acronyms

> Domain-specific acronyms used in this repo's code and docs. Generic programming
> acronyms (HTTP, JSON, gRPC, URL, API, JWT) are NOT listed here — only domain terms
> that a new engineer wouldn't infer from context.
>
> Auto-generated by `/m-docs:acronyms-docs`. Add entries as new acronyms are introduced.

This repo is **Grafana Beyla**, an eBPF zero-code instrumentation agent, so the glossary
is kernel/eBPF/OpenTelemetry domain rather than Meesho business domain. None of these
terms appear on the [company-wide acronyms wiki](https://meesho.atlassian.net/wiki/spaces/EW/pages/428310542/Acronyms+and+their+meanings),
and none are candidates for upstreaming there.

## Provenance and confidence

Every expansion above is grounded in text found in this repo except the three noted here,
which are inferred and worth a maintainer's confirmation:

- **OATS** — the repo only ever says "the OATS harness". The expansion comes from the
  upstream `grafana/oats` project name, not from this tree.
- **olly** — inferred from the `appolly` / `infraolly` package pair. No file spells it out.
- **ASPNET** / **CORECLR** — used purely as environment-variable markers; the expansions are
  .NET platform names rather than anything this repo defines.

Scope note: mining covered `cmd/`, `pkg/`, `internal/`, `examples/`, `ops/`, `charts/`,
`deployments/`, `scripts/`, and `docs/sources/`. It excluded `vendor/`, the `.obi-src`
submodule, and the bundled third-party `examples/quickstart/cpp/httplib.h`. Acronyms that
live only in OBI upstream (`CO-RE`, `DWARF`) are therefore absent — re-run against the
submodule if you need those.
